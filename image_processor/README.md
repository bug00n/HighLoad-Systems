# Image Processor
<p align="justify">
A high-performance image processing service designed for handling large-scale workloads.
</p>

---

###  Features

- Image resizing
- Filters: crop, grayscale, negative, sharpening, edge detection, gaussian blur and tunnel rotate.
- Sequential application of filters

---

### Technology Stack

- C++ 20+

---

### Examples

```bash
./image_processor.exe .../input.bmp .../output.bmp -filter1 -param1 -param2 ... -filter2 -param1 -param2 ... 
```
