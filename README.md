# HighLoad-Systems

## Motivation

<p align="justify">
In this repository, I practice my backend development skills and study the basics of high-load and distributed systems.
</p>

<p align="justify">
Below you can see all my projects:
</p>

---

* ### __*[echo-server ★](https://github.com/bug00n/HighLoad-Systems/tree/main/echo-server-cpp)*__

    <p align="justify">
    In this project, I learned how TCP/IP works and how sockets are created at a low level on Windows.
    I also learned Markdown and practiced it by writing documentation.
    </p>

* ### __*[http-server ★](https://github.com/bug00n/HighLoad-Systems/tree/main/HTTP-server-cpp)*__

    <p align="justify">
    This was my first project where I split the code into multiple files.
    I learned how header and source files work and how to organize a C++ project.
    </p>

* ### __*[account-manager ★★](https://github.com/bug00n/HighLoad-Systems/tree/main/account-manager-py)*__

    <p align="justify">
    In this project, I learned how to integrate Redis and PostgreSQL into a Python application.
    I also tried FastAPI for the first time.
    I had some problems while testing the API with Uvicorn, but solving them helped me better understand how Uvicorn and processes work.
    </p>

* ### __*[messager ★★](https://github.com/bug00n/HighLoad-Systems/tree/main/messager-cpp)*__

    <p align="justify">
    In this project, I worked with asynchronous programming in C++ and experimented with OOP.
    I solved dependency-related problems by using header files.
    I also encountered several segmentation faults, including one caused by the fact that class members are initialized in the order in which they are declared in the class, rather than the order specified in the constructor's initialization list.
    This was also my first experience with Boost.Asio.
    </p>

* ### __*[image processor ★★](https://github.com/bug00n/HighLoad-Systems/tree/main/image_processor)*__

    <p align="justify">
    I am proud of this project. It is a console application that applies filters with different parameters to 24-bit BMP images.
    The project taught me how to write tests in C++ and how to work with exceptions.
    I also learned how to build a C++ application.
    </p>

* ### __*[in-memory cache ★★★](https://github.com/bug00n/HighLoad-Systems/tree/main/cache)*__

    <p align="justify">
    Implemented a high-performance multithreaded in-memory cache in C++20 using a sharding architecture to minimize lock contention.
    The system supports synchronous and asynchronous operations and is optimized for highly concurrent workloads.
    Benchmarking showed near-linear scaling up to an optimal ratio of approximately 4 clusters per thread, validated through extensive stress testing.
    </p>
